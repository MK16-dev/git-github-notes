# What is GitHub?


---

# 1. Introduction

GitHub is a cloud-based platform that hosts Git repositories. It allows developers to store, manage, and collaborate on projects using Git.

While Git tracks changes locally on your computer, GitHub stores your repositories online so they can be accessed from anywhere and shared with others.

---

# 2. Why Do We Need GitHub?

Imagine your laptop crashes or you buy a new computer.

If your project exists only on your laptop, you could lose your work.

By pushing your repository to GitHub:

- Your code is backed up online.
- You can access it from any computer.
- You can collaborate with other developers.
- You can showcase your projects to recruiters and employers.

---

# 3. How Does GitHub Work?

The basic workflow is:

1. Create a local Git repository.
2. Write or modify your code.
3. Commit your changes using Git.
4. Push the commits to GitHub.
5. GitHub stores your repository in the cloud.

---

# 4. Git vs GitHub

| Git | GitHub |
|-----|---------|
| Version Control System | Cloud hosting platform |
| Installed on your computer | Runs on the internet |
| Tracks changes | Stores repositories online |
| Works offline | Requires internet for most operations |
| Free and open-source | Provides hosting and collaboration features |

# 9. Common Misconceptions

### GitHub is not Git

Git and GitHub are different tools.

Git works without GitHub.

GitHub depends on Git.

---

### GitHub is not the only Git hosting platform

Other popular platforms include:

- GitLab
- Bitbucket
- Azure Repos
