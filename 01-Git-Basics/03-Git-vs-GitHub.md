# Git vs GitHub

> **Level:** Beginner

---

# 1. Introduction

Many beginners think Git and GitHub are the same thing, but they are completely different.

**Git** is a Version Control System (VCS) that tracks changes in your project.

**GitHub** is a cloud-based platform that hosts Git repositories, making it easy to back up code, collaborate with others, and share projects.

In simple words:

- **Git = Tool**
- **GitHub = Platform**

---

# 2. What is Git?

Git is software installed on your computer.

It allows you to:

- Track changes in files
- Save project versions
- Restore previous versions
- Create branches
- Merge code
- Work completely offline

Git manages your project locally.

---

# 3. What is GitHub?

GitHub is an online platform that stores Git repositories.

It allows you to:

- Store projects in the cloud
- Collaborate with developers
- Share code publicly or privately
- Contribute to open-source projects
- Showcase projects as a portfolio

GitHub requires Git to manage repositories.

---

# 4. Git vs GitHub Comparison

| Git | GitHub |
|------|---------|
| Version Control System | Cloud Hosting Platform |
| Installed on your computer | Runs on the internet |
| Tracks file changes | Stores Git repositories online |
| Works offline | Internet required for most operations |
| Free and open-source | Free and paid plans available |
| Created by Linus Torvalds | Owned by Microsoft |

---

# 5. Relationship Between Git and GitHub

Git and GitHub work together.

Typical workflow:

1. Create or modify files.
2. Git tracks the changes.
3. Commit the changes using Git.
4. Push the commits to GitHub.
5. GitHub stores the repository online.

# 7. Real-Life Example

Imagine writing a book.

**Git** is like your computer where you write and save every version of the book.

**GitHub** is like Google Drive, where you upload the book so you can access it from anywhere and share it with others.

---

# 8. Advantages of Git

- Version control
- Fast
- Offline support
- Branching and merging
- Easy rollback

---

# 9. Advantages of GitHub

- Online backup
- Collaboration
- Portfolio
- Pull Requests
- Issue tracking
- CI/CD integration using GitHub Actions

---

# 10. Common Misconceptions

### Git and GitHub are the same.

❌ False

Git is software.

GitHub is a hosting platform.

---

### GitHub is required to use Git.

❌ False

Git works perfectly without GitHub.

---

### Git can only be used for programming.

❌ False

Git can track any type of file, including:

- Documents
- Notes
- Images
- Configuration files

---

---

# 12. Key Takeaways

- Git is a Version Control System.
- GitHub is a cloud-based Git repository hosting platform.
- Git manages project history locally.
- GitHub stores repositories online.
- Git and GitHub are complementary but not the same.
- You can use Git without GitHub, but GitHub relies on Git.
